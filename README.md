
# Abbey Road · 大学生课表app

一款全新的多平台课表应用，支持自动定闹钟、日程，借助手机上的多模态 AI（豆包、DeepSeek 等）轻松完成课表导入。

使用 AI 编程，感谢蓝色大肥鱼的辛勤付出。

## 特点

- 双端观感一致：手机和电脑共用同一套界面代码，不是两套各写一遍的 UI。
- 导入不用手敲：内置提示词，交给豆包、DeepSeek 等能看图的 AI 读课表截图，把回复粘回来即可；解析器对格式比较宽容，也能手动改。
- 自动定日程：把课程写入系统日历、设置闹钟，只需点确认。


## 功能

**课表与日程**

- 今日一屏：左「本周概览」、中「今日日程」、右「最近的课」，点任意一栏放大，✕ 或 Esc 收起。
- 周表网格：日期在上、节次在左，课程块按节次跨行；顶部周次条可跳任意周。
- 月视图：看整月课程密度，有课的日期带圆点，点日期直接跳转。
- 变动支持：单双周、周次范围、调课、停课、补课、换教室、换时间；冲突自动检测，相邻连堂课自动合并。
- 状态变色：「最近的课」按离上课时间自动变色（默认 15 分钟内红、30 分钟内黄、上课中蓝），阈值和颜色可改。

**导入与同步**

- AI 导入：内置固定提示词（`ar-txt-1.1.0`），复制给 AI 并附上课表截图，把结果粘贴回来即可。
- 格式宽容：JSON 数组、Markdown 表格、制表符 / 逗号分隔、逐行中文散文都能还原成课程行，解析失败的条目会逐条提示。
- 手动添加：课程、考试、讲座、活动都可以手动录入。
- 配置文件同步：导出 JSON，在另一台设备导入；导入前先预览，冲突逐条确认。

**系统集成**

- 导航：自动去掉「305 教室」这类细节并补上大学名，一键跳高德 / 百度 / 系统地图；线上课程不导航。
- 日历与闹钟：Android 通过系统意图写入日历、设置闹钟；Windows 导出 `.ics` 交给系统日历。
- 桌面卡片（Android）：5 种小组件，今日头、下一节课、今日课程、本周课表、快捷入口。
- 触觉反馈：重要操作有震动，滑块之类只保留视觉反馈。

**个性化**

- 深浅色模式、主题色、毛玻璃强度（四档）、动画速度（0.5× / 1× / 1.5×）。
- 两套布局预设「左右」「上中下」，各栏宽高用滑块调整，按屏幕断点分别记忆。
- 设置分 9 类：外观、布局与尺寸、桌面卡片、课程与课表、提醒与通知、导入与同步、系统集成、数据与备份、关于与帮助。
- 首次启动 6 步引导，可跳过（长按「下一步」），也能重看。

| --- | --- | --- |
| Android | `AbbeyRoad-v0.1.9.apk` | Android 8.0+（`minSdk 26` / `targetSdk 34`）；权限只有震动、闹钟、通知 |
| Windows | `AbbeyRoad-Setup-v0.1.9.exe` | Windows 10 / 11 x64，需要 WebView2 |

安装后第一次打开会有 6 步引导，跟着走一遍即可知道每个按钮在哪。演示课表可以随时清空（设置 → 数据与备份）。

## 快速上手

**1. 把课表导进来（推荐 AI 流程）**

打开「导入 → ① 提示词」，复制内置提示词；把提示词和课表截图一起发给 DeepSeek / 豆包；把 AI 回复粘贴到「② 课表文本」，确认预览无误后点右下角「应用到课表」。

**2. 调成自己的样子**

设置 → 课程与课表，填学期名称、开学第一周周一、总周数、节次表；设置 → 外观，选深浅色、主题色与毛玻璃强度；设置 → 布局与尺寸，选「左右」或「上中下」。

**3. 同步到另一台设备**

设置 → 导入与同步 → 导出 JSON，把文件传到手机 / 电脑，在另一端的「导入 → 手动导入 · 配置文件」里选择该文件。导入前会给出合并预览与冲突清单。

## 导入格式（AR-TXT）

一行一门课，字段用全角竖线 `｜` 分隔（半角 `|` 也认）；第一行是固定表头：

```text
AbbeyRoad 课表 v1
开学日期：2026-09-07
高等数学 ｜ 周一 ｜ 1-2 ｜ 1-16 ｜ XX大学 信息楼305 ｜ 张三 ｜ 需带教材 ｜ 蓝
大学物理 ｜ 周三 ｜ 5-6 ｜ 双周 ｜ XX大学 物理楼101 ｜ 李四 ｜  ｜ 橙
英语 ｜ 周五 ｜ 3-4 ｜ 1-16 ｜ 文科楼401
调课 ｜ 高等数学 ｜ 2026-10-08 ｜ 周四 ｜ 1-2 ｜ XX大学 信息楼201 ｜ 国庆调休
停课 ｜ 大学物理 ｜ 2026-10-01
考试 ｜ 高等数学 期中 ｜ 2026-11-12 ｜ 14:00-16:00 ｜ XX大学 信息楼305 ｜ 闭卷
```

字段顺序固定为 `课程名｜星期｜节次｜周次｜地点｜老师｜备注｜颜色`，没有的字段留空或用 `-`。星期写「周一…周日」，节次写 `1-2`，周次写 `1-16` / `单周` / `双周` / `全周`，颜色写「红 / 橙 / 黄 / 绿 / 青 / 蓝 / 紫 / 粉 / 棕 / 灰」或 `#RRGGBB`（留空自动分配）。缺字段会按位置补位并给提示，不会串行。

## 数据与隐私

- 所有数据保存在本机：Android 用 WebView 本地存储，Windows 用 `%LOCALAPPDATA%\Abbey Road`。
- 应用不发起任何网络请求，不收集数据，没有账号体系；导出的配置文件由你自己保管。
- 配置文件是 JSON（`kind: "abbeyroad.sync"`），带 schema 版本号，导入前先预览、冲突逐条确认。
- 源码包与构建脚本不含任何密钥：签名口令和工具链路径从环境变量或 `build.local.ps1` 读取，两者都在 `.gitignore` 里。

## 技术架构

一套 Web 界面内核 + 两端原生外壳，界面与业务逻辑 100% 共用：

```
abbey-road/
├─ app/              ← 唯一界面实现（HTML/CSS/JS），Android 与 Windows 共用
│  ├─ index.html
│  ├─ css/           tokens.css（设计令牌）· app.css（布局与组件）
│  └─ js/            core（数据 / 课表计算）· mdparse（文本解析）· ui（布局 / 动画）
│                    panels（导入 / 设置 / 引导）· bridge（平台桥）· widgetdata
├─ android/          ← Android 外壳：Java + WebView + ARBridge（震动 / 日历 / 闹钟 / 地图 / 文件）
├─ windows/          ← Windows 外壳：C# + WebView2 + 原生桥 + 自研安装器
├─ tools/            ← 开发脚本（逻辑回归测试、CDP 驱动、逐帧抓图、窗口抓取）
└─ docs/screenshots/ ← 截图
```
